# Домашнее задание: реализация метода бисекции

## Задание

Разработать консольную программу на **любом языке программирования**, которая находит приближённый корень нелинейного уравнения методом бисекции (методом деления отрезка пополам).

Для решения использовать функцию:

**f(x) = x³ − x − 2**

Необходимо найти корень уравнения:

**x³ − x − 2 = 0**

на отрезке:
          
**[1; 2]**

с точностью:

**ε = 0,0001**

### Требования к программе

Программа должна:

1. Принимать или задавать начальные границы отрезка `a` и `b`. точность `ε`.
2. Реализовать метод бисекции.
4. Остановить вычисления, когда достигнута заданная точность **ε = 0,0001**.
5. Вывести на консоль найденное приближённое значение корня.
6. Запускаться
