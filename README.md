1. Программа предназначена для поиска пиближенного решения нелинейного уравнения.
В процессе выполнения программа последовательно уменьшает интервал, пока не достигнется определенная точность, после чего выводит ответ.
2. Задаются начальные границы отрезка, после точность вычислений. Далее проверяется условие продолжения вычесления. После этого если произведение значений функции на левом краю и в середине f(a)*f(c)<= 0: b=c. Корень слева сдвигаем вправую границу else: a=c. Корень справа сдвигаем левую границу. Как только условие перестает выполняться, то вычесления прекращаются.
